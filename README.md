One funny line for make.fun's "The One-Line Laugh" bounty: a single sentence of at most 200 characters, judged pairwise by a house judge that weighs a real surprise at the end, an everyday truth, and economy of words.

## Run it

```sh
python3 main.py
```

The program writes the line to /output/entry.txt, after a self-check gate (one sentence, 1 to 200 characters, UTF-8, no trailing newline).
